# Customer-Churn-Prediction-using-Machine-Learning
## Project Overview

Customer churn is a critical business challenge, particularly in subscription-based industries. This project develops machine learning models to predict customer churn and identify customers at risk of leaving.

## Business Problem

Acquiring a new customer costs significantly more than retaining an existing one. By identifying customers likely to churn, organizations can take proactive measures to improve customer retention and profitability.

## Dataset

- Dataset Size: 7043 customers
- Target Variable: Churn
- Features:
  - Demographics
  - Service usage
  - Billing information
  - Contract details
